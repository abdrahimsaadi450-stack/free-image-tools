JPG vs PNG

JPG is commonly used for photographs because it can produce relatively small file sizes. PNG is a lossless image format that is often useful for graphics, screenshots, logos and images where image quality needs to be preserved during saving.

Converting an existing JPG to PNG does not recover details that were already lost because of JPG compression. The conversion mainly changes the file format.
